     Query Processing
        • Find documents matching query {ink AND wink}
             1. Load inverted lists for each query word
             2. Merge two postings lists à Linear merge
        • Linear merge à O(n)
           n: total number of posts for all query words

                                                                 1: f(0,1) = 0

     Phrase Search
        • Find documents matching query “pink ink”
             1. Find document containing both words
             2. Both words has to be a phrase

        He likes to wink, and drink pink ink Convert to bigrams

             • Fast, but index size will explode!
             • What about trigram phrases?

     Query Processing: Proximity
        • Find documents matching query “pink ink”
             1. Use Linear merge
             2. Additional step: check terms positions
        • Proximity search:
           pos(term1) – pos(term2) < |w| à #5(pink,ink)

     Query Processing: Simple implementation
        • For each term in query à retrieve posting list
        • AND à Intersection (⋂) between posting lists
        • OR à Union (⋃) of posting lists
        • NOT à inverse of posting list (all docs not in the list)
             • Usually only combined with AND operator.
        • Phrase search à AND + check pos2-pos1 == 1
        • Proximity search à AND + check |pos2-pos1| ≤ n
