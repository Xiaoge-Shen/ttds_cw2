\subsubsection{Comparison of MI and $\chi^2$ Rankings}

MI identifies corpus-exclusive terms (all top words score identically: $\log_2(N/N_c)$) but favors rare vocabulary with limited interpretability. $\chi^2$ highlights high-frequency discriminators that capture thematic identity: ``muhammad/believers'' (Quran theology), ``israel/king/david'' (Hebrew monarchy), ``jesus/christ/disciples'' (Christian Gospel). MI measures lexical uniqueness (perfect discrimination even for singletons), while $\chi^2$ tests statistically significant deviation, favoring frequent terms. For corpus characterization, $\chi^2$ proves more semantically meaningful.

\section{Text Classification}

\subsection{Dataset and Experimental Setup}
The sentiment classification task involved three-way classification (positive, negative, neutral) of tweets. The dataset comprised 18,646 training samples with the following distribution:
\begin{itemize}
    \item Neutral: 8,789 (47.1\%)
    \item Positive: 5,979 (32.1\%)
    \item Negative: 3,878 (20.8\%)
\end{itemize}

The data was shuffled and split 90/10 into training (16,781) and development (1,865) sets using stratified sampling to maintain class proportions. All experiments used random seed 42 for reproducibility. A separate test set of 4,662 samples was provided for final evaluation.

\subsection{Baseline System}
The baseline system followed the standard approach:
\begin{itemize}
    \item \textbf{Preprocessing}: Lowercasing, basic tokenization
    \item \textbf{Features}: Bag-of-words (BOW) with \texttt{CountVectorizer} (max\_features=10,000, min\_df=2)
    \item \textbf{Classifier}: Linear SVM with $C=1000$, trained using \texttt{LinearSVC}
\end{itemize}

\subsection{Error Analysis}
Three misclassifications reveal common challenges:

\begin{enumerate}
    \item \textbf{Political news}: ``Wikileaks: Clinton Foundation...'' (Pred: neutral, Act: negative). Factual style masks negative implications; BOW cannot capture ``Raises Questions'' as implicit criticism.
    
    \item \textbf{Positive keywords}: ``Bob Dylan... all star lineup...'' (Pred: positive, Act: neutral). ``All star'' triggers false positive despite event announcement being informational.
    
    \item \textbf{Context-dependent}: ``Iran islamist revolution... blinded by fact's clarity'' (Pred: positive, Act: negative). ``Clarity'' interpreted positively; model misses ``blinded by'' criticism.
\end{enumerate}

\subsection{Improved System}
Four targeted improvements address error analysis findings:

\begin{enumerate}
    \item \textbf{TF-IDF}: Down-weights common words, up-weights discriminative terms (\texttt{sublinear\_tf=True}, \texttt{max\_df=0.95}). Improved precision distinguishing neutral from positive/negative.
    
    \item \textbf{Bigrams}: Captures negation (``not good'') and multi-word expressions (\texttt{ngram\_range=(1,2)}). Negative class F1: 0.446→0.500 (+12\%).
    
    \item \textbf{C=500}: Reduced from 1000 to mitigate overfitting. Better generalization while maintaining high training performance.
    
    \item \textbf{20K features}: Expanded from 10K to accommodate bigrams, enabling richer context representation.
\end{enumerate}

\subsection{Performance Analysis}

Improvements achieved +7.5\% (dev) and +8.5\% (test) gains. Per-class: positive (+6.6\%/+7.4\%), negative (+12.1\%/+12.0\%), neutral (+5.0\%/+6.4\%). Negative class's substantial gain validates error analysis hypothesis: bigrams effectively capture negation patterns.

Test performance (0.564) slightly exceeds dev (0.557, +0.007), indicating: (1) no overfitting to dev set—hyperparameters generalize well, (2) representative 90/10 stratified split maintained distribution, (3) robust TF-IDF+bigram features transfer across partitions. Consistent dev/test performance (<1\% deviation) suggests model maintains ~0.56 F1 on similar data.

\section{Conclusion}

This coursework demonstrated: (1) IR evaluation metrics implementation with significance testing revealing small sample limitations (n=10), (2) complementary feature selection methods (MI: exclusive vocabulary, $\chi^2$: high-frequency discriminators, LDA: thematic structure) capturing religious texts' nature quantitatively (Quran coherence: 0.358, NT: 0.143, OT: 0.080), and (3) error-driven classification improvement (+8.5\% gain) validating targeted feature engineering (TF-IDF+bigrams).

Key lesson: computational text analysis requires understanding algorithms' assumptions and limitations, not just implementation. Main challenges: nDCG formula correctness, Chi-square correlation handling, overfitting mitigation. Future directions: larger query sets for statistical power, hierarchical LDA for sub-themes, transformer-based sentiment classifiers.
